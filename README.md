# 静读 Quiet Reader

仅供个人使用的 Android 离线 EPUB 阅读器。无需账号、服务器或联网权限。

## 下载

- [安装包：静读 1.1](静读-1.1.apk)
- [完整 Android 项目源码](静读-Android完整项目.zip)
- [手机安装说明](手机安装说明.md)

点击文件后，使用 Download raw file 下载。手机安装需要 Android 8.0 或更高版本。

## 功能

通过系统文件选择器打开本地 EPUB，支持翻页、调整字号、深色模式和记忆阅读位置。书籍和阅读数据保存在本机。

## 1.1 更新

- 跟随手指的横向覆盖翻页，带阴影和松手动画。
- 短距离拖动自动回弹，快速滑动或长距离拖动完成翻页。
- 上一页、下一页按钮使用相同动画，支持跨章节翻页。
- 保留字号、深色模式和阅读进度；可覆盖安装 1.0。

已在 Android 模拟器验证手势、回弹、跨章节、字号、主题和阅读位置恢复。

## 编译

下载并解压完整项目压缩包，在 Android Studio 中打开 QuietReader 项目，按项目 README 操作。压缩包包含源代码、构建脚本和测试，不包含私人签名密钥。

首次准备开发环境和构建依赖可能需要联网；阅读功能完全离线。
